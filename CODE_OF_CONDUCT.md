# Código de conduta

O GranaPaCá adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). O texto completo vale para todos os espaços do projeto: issues, PRs, discussões e qualquer outro canal oficial.

Em resumo: trate todas as pessoas com respeito, aceite críticas construtivas e não tolere assédio, discriminação nem exposição de dados pessoais de ninguém.

## Como relatar

Relate comportamentos inaceitáveis a quem mantém o projeto, [@igorgmassi](https://github.com/igorgmassi). Se o perfil não tiver um contato público, abra uma issue pedindo um canal privado, sem detalhes do caso. Todos os relatos são tratados com sigilo.
