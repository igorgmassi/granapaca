# profiles

Perfis do guia inicial em YAML. Cada perfil (desenvolvedor, motorista de app, estudante, professor...) gera regras de essencialidade e de marca, sempre com uma explicação curta que o app mostra para a pessoa.

O formato e o JSON Schema que o CI vai validar ainda estão em definição. Para propor um perfil, veja o [guia de contribuição](../CONTRIBUTING.md#propondo-um-perfil-para-o-guia-inicial).
